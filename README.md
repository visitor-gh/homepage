# (주)노금휀스철망 — Homepage

회사 홈페이지와 관리자 페이지. 깔끔하고 묵직하면서도 접근성 있는 톤으로 재구성했습니다.

## 구조

```
homepage/
├── index.html         # 메인 페이지
├── admin.html         # 관리자 페이지
├── css/
│   ├── style.css      # 메인 디자인 시스템
│   └── admin.css      # 관리자 페이지 스타일
└── js/
    ├── main.js        # 메인 페이지 인터랙션 (네비, 필터, 폼)
    ├── admin.js       # 관리자 CRUD (localStorage 기반)
    └── image-slot.js  # 이미지 드래그 앤 드롭 컴포넌트
```

## 주요 기능

### 메인 페이지 (`index.html`)
- Hero · 회사소개 · 서비스(6종) · 시공사례 · 견적 문의
- 스크롤 시 헤더 변화, 섹션별 페이드 인 애니메이션
- 포트폴리오 카테고리 필터링
- 견적 문의 폼 (전화번호 자동 포맷, 유효성 검증)
- 모든 이미지 자리는 `<image-slot>` 컴포넌트 — 사용자가 직접 드래그해서 이미지 추가 가능

### 관리자 페이지 (`admin.html`)
- 대시보드 통계 카드
- 포트폴리오 이미지 추가 / 수정 / 삭제 (모달 기반)
- 견적 문의 목록 조회 및 상태 업데이트
- 데이터는 `localStorage`에 저장 (백엔드 연동 시 fetch로 교체)

## 디자인 시스템

| 토큰 | 값 |
|---|---|
| Background | `#F6F4F0` (warm off-white) |
| Surface | `#FFFFFF` |
| Ink | `oklch(0.22 0.012 250)` |
| Accent | `oklch(0.62 0.13 52)` — warm copper |
| Steel | `oklch(0.20 0.014 250)` |
| Font (sans) | Noto Sans KR |
| Font (mono) | JetBrains Mono — 라벨 / 코드 |

## 이미지 추가 방법

1. 메인 페이지를 열고 빈 이미지 자리 위에 이미지 파일을 드래그
2. 브라우저에 저장되어 새로고침 후에도 유지됨
3. 또는 관리자 페이지에서 이미지 URL을 등록
